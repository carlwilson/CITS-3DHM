:description: The Content Information Type Specification for 3D Heritage Model data (CITS 3D HM) is designed to be used for the transfer to archives as well as for records exchange \
between different organisations and repositories of 3D cultural heritage model data, produced through any method and recorded in any format such as: point cloud models \
(for example by: photogrammetry, laser scanning, structured light); CAD based models (including building information models, BIM amd heritage building information models, HBIM); volumetric models \
(computer tomography); GIS models; and procedural modelling (reconstructions). This specification is supported by METS profiles for the Root and Representation METS files, \
an example package and this Guideline document.
